Place unit images here.

Format : PNG with transparent background
Size   : square, 128x128 or 256x256 recommended (any size works, it is scaled to the tile automatically;
         on the map a unit is drawn at roughly 44 px, in the side panel at 46-52 px)
Facing : draw the unit facing RIGHT (like the placeholder drawings)
Names  : from the `sprite` column in data/units.csv (default: <unit id>.png):

  rifleman.png  trooper.png  light_tank.png  medium_tank.png  heavy_tank.png
  medic.png  ambulance.png  truck.png

Missing images are replaced by a simple drawn placeholder. The team colour ring is drawn automatically
around every unit, so do not paint it into the image.
